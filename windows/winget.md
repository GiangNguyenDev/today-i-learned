# Definition

Winget is a command-line tool developed by Microsoft that allows you to discover, install, upgrade, and configure applications on Windows using simple text commands.

Think of Winget (the Windows Package Manager) as the "App Store" for people who prefer typing over clicking.

# Winget Commands

| Command        | Shortcut                              |
| -------------- | ------------------------------------- |
| list / ls      | Display installed packages            |
| install / add  | Installs the given package            |
| uninstall / rm | Uninstalls the given package          |
| upgrade        | Shows and performs available upgrades |
